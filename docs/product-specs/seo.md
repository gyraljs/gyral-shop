# SEO (google-seo-fundamentals skill)

- Unique `<title>` and meta description per page; canonical URLs (filters that don't change
  content are canonicalized to the base listing); `noindex` on account, cart, checkout, admin.
- `/sitemap.xml` (home, content, departments, categories, products) and `/robots.txt`.
- Structured data: `Product` (offers, availability, aggregateRating) on product pages,
  `BreadcrumbList`, `Organization` + `WebSite` (with SearchAction) on home.
- Open Graph/Twitter meta for product pages. Images have alt text.
